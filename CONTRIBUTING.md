# Contributing

Thanks for your interest in improving `gh-mine`! This is a small project — keeping
it simple and dependency-light is an explicit goal.

## Development

`gh-mine` is a single Bash script with no build step.

```bash
# clone
git clone https://github.com/majiayu000/gh-mine.git
cd gh-mine

# run from source (no install needed)
./gh-mine --help

# syntax check (must pass)
bash -n gh-mine install.sh

# lint (optional, if shellcheck is installed)
shellcheck gh-mine install.sh
```

## Before opening a PR

- Keep changes minimal and in scope.
- Run `bash -n gh-mine install.sh` — it must pass.
- Use rebase, not merge, to keep history clean.
- DCO: sign your commits (`git commit -s`).
- Do **not** add AI-generated markers (`Co-Authored-By`, `Generated by ...`) to
  commit messages.

## Reporting issues

Use the issue templates under `.github/ISSUE_TEMPLATE/`.
