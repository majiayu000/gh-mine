# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `gh-mine`, please do **not** open a
public issue.

Report it privately through GitHub's vulnerability reporting:

**https://github.com/majiayu000/gh-mine/security/advisories/new**

Please include:

- A description of the issue and its potential impact
- Steps to reproduce
- The affected version or commit

You should receive an initial response within a few days.
